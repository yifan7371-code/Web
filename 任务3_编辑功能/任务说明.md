# 任务3 编辑分支

实现目标：在任务2的父容器监听器中增加编辑分支，用 button[data-action] 识别操作，以 if 删除 / else if 编辑 / else 切换保持互斥。通过 li 的数字 id 从完整 todos 找到原文字。

输入检查：取消先返回，再对字符串 trim。空值拦截，原文字未变化时不保存和重画；不存在的 id 不更新。有效内容用 map 和对象展开只改 text，保留 id、completed 和非目标任务，依次保存、重画，并按保存结果提示。

本次使用 AI 完成代码实现、边界分析及浏览器测试，报告在原有使用情况栏目中如实记录。

实测共19项通过：包括动态新增后编辑、按钮内文字点击、取消、空字符串、纯空格、无变化输入、状态保留、筛选中编辑后刷新、无效id、未知操作、不可变更新、存储失败提示与原交互回归。两个主动构造的反例单独记录：未定义 t.text 导致 ReferenceError，null.trim() 导致 TypeError，未将反例放进应用。
